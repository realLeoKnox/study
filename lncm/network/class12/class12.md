# 第 12 课　路由器与路由协议、广域网基础

> 2026-11-04（周三晚）· 理论课 · 教材 4.3 网络互联（续，含 4.3.3 路由协议）、5.1 广域网的基本概念

## 一、三层交换机

| 随堂题 | 答案 |
|---|---|
| 三层交换机转发**同一网段**的数据包时，实际走的是？ | **二层交换模块**（同网段查 MAC 表就行，不用路由） |
| “一次路由，多次交换”中“多次交换”的含义？ | **后续数据包由二层直接转发** |
| 三层交换机能完全替代核心路由器承担广域网互联吗？ | **错误**：端口类型简单，复杂广域网接口与路由能力仍靠路由器 |

> **工程现实**
> “一次路由、多次交换”是早期流缓存式三层交换的说法。现在的三层交换机在 ASIC 里放完整的转发表，**每个包都在硬件里按三层查表**，不存在“第一个包走软件”。

## 二、路由器

- 工作在**网络层**，看 **IP 地址**；把局域网与广域网（或不同网络）连接起来
- 核心是**路由选择 + 分组转发**；每个接口是一个独立网段，**隔离广播域**
- 功能：**地址映射**（知道下一跳 IP，用 ARP 查 MAC）、**数据转换**（不同网络帧格式不同，拆旧帧头、按出口重新封装，必要时分片）、**路由选择**、数据转发、过滤隔离、流量控制、网络管理

> **补充**
> 每过一个路由器：**IP 包基本不变**（只有 TTL 减 1、校验和重算），但**二层帧头每一跳都是新的**。

### 路由表的字段与选路

| 课件说法 | 华为 `display ip routing-table` | 含义 |
|---|---|---|
| 目的地址 + 子网掩码 | Destination/Mask | 能到哪个网段 |
| 路由信息来源 | Proto | Direct、Static、RIP、OSPF… |
| 路由优先级 | Pre | 不同来源的可信程度，**越小越优先** |
| 路由开销 | Cost | 同一来源内比路径好坏，**越小越好** |
| 下一跳 | NextHop | 交给谁 |
| 输出端口 | Interface | 从哪个口发出 |

![](img/route-select.svg)

*图 12-1　选路顺序：先最长前缀匹配，再比优先级，最后比开销*

华为默认优先级：**直连 0、OSPF 10、静态 60、RIP 100、BGP 255**（思科叫管理距离，数值不同）。

### 三类路由

| 类别 | 来源 | 特点 | 适用 |
|---|---|---|---|
| 直连路由 | 接口配 IP 且 UP，**自动生成** | 不用配置，只到直连网段 | 所有路由器 |
| 静态路由 | **管理员手工配置** | 简单、省资源、可控；拓扑变化不能自动调整 | 小型稳定网络、默认路由 |
| 动态路由 | 路由协议**自动学习** | 自适应、有冗余；开销大、复杂 | 大中型网络 |

```
ip route-static 192.168.2.0 24 10.0.0.2    # 静态路由
ip route-static 0.0.0.0 0 10.0.0.2         # 默认路由
display ip routing-table
```

## 三、互联设备总对比

| 设备 | 层次 | 核心功能 | 主要局限 |
|---|---|---|---|
| 中继器 | 物理层 | 放大再生信号 | 不识别地址，不隔离冲突域 |
| 集线器 | 物理层 | 多端口中继，广播转发 | 一个冲突域，共享带宽 |
| 网桥 | 数据链路层 | 按 MAC 过滤转发 | 端口少，不隔离广播域 |
| 交换机 | 数据链路层 | 多端口网桥，每口一个冲突域 | 默认不隔离广播域 |
| 三层交换机 | 网络层（兼二层） | 局域网内 VLAN 间高速转发 | 广域网接口与复杂功能弱 |
| 路由器 | 网络层 | 路由选择、隔离广播域 | 转发延迟较大，配置复杂 |
| 网关 | 传输层及以上 | **协议转换** | 实现复杂，效率最低 |

**网关**：连接**高层协议不同**的网络，分为**数据网关**（协议转换）、**应用网关**（某种应用的格式转换，如邮件网关、代理）、**安全网关**（防火墙、VPN 网关）。

> **易错点**
> 电脑里设置的“默认网关”其实是**路由器**（三层），不是课本里做协议转换的网关设备。

## 四、路由协议（4.3.3）

- 静态：简单小型网络；动态：复杂大型网络（严格说静态路由不算协议，路由器之间不交换信息）
- **IGP 域内**（一个 AS 内部）：RIP、OSPF、IS-IS；**EGP 域间**（AS 之间）：**BGP**

### RIP 与 OSPF

| 对比项 | RIP | OSPF |
|---|---|---|
| 协议类型 | 距离向量 | 链路状态 |
| 交换对象 | 只和**相邻**路由器 | 区域内**所有**路由器（泛洪） |
| 交换内容 | **整张路由表** | **链路状态**（LSA） |
| 更新时机 | **定期**，每 30 s | **链路变化时** |
| 算法 | Bellman-Ford | Dijkstra（SPF） |
| 度量 | **跳数**，最多 15，**16 = 不可达** | 开销 cost（按带宽） |
| 收敛 | 慢，会计数到无穷 | 快，无环路 |
| 规模 | 小型 | 中大型，可分区域 |

**RIP 的隐患：好消息传得快，坏消息传得慢。** A—B—C 一条线，C 后面的网络断了，B 收到 A 发来“我到那里 2 跳”就信了，两边互相抬价直到 16 跳才确认不可达，期间形成环路（**计数到无穷**）。对策：**水平分割、毒性逆转、触发更新、抑制计时器**。

> **记忆口诀**
> RIP：邻居、全表、定时、跳数、慢、小；OSPF：全区、链路、触发、开销、快、大。

## 五、第 5 章　广域网的基本概念（5.1）

### 1. 定义与特点

- 广域网又称**远程网**，其**通信子网主要使用分组交换技术**
- 记忆锚点：**距离远 + 运营商修的路 + 分组交换**
- 与局域网比：速率较低、时延较大；典型速率 **56 kbit/s ～ 155 Mbit/s**（56k Modem 到 SDH STM-1）
- 5 个特点：**通信为本、范围千里、靠运营商、只做三层（只涉及下三层）、运维不易**
- 随堂题：与局域网相比广域网最典型的特征 → **无固定拓扑**（不规则网状，维护困难）

> **工程现实**
> “速率低”是老数据，现在骨干网是 100G、400G；“时延大”仍成立，因为光在光纤里每毫秒只走约 200 km。

### 2. 广域网的组成

![](img/wan-parts.svg)

*图 12-2　从用户到运营商骨干*

**DTE 与 DCE**：DTE（数据终端设备，如路由器、电脑）是数据的源和宿；DCE（数据电路端接设备，如 Modem、CSU/DSU）负责信号转换并**提供时钟**。**谁提供时钟，谁就是 DCE**（发令员与听令者）。

### 3. 三种连接方式

| 对比项 | 专线 | 电路交换 | 分组交换 |
|---|---|---|---|
| 是否独占 | 长期独占 | 通信期间独占 | 共享 |
| 建立过程 | 一次开通、永久连接 | 每次建立 → 通信 → 释放 | 一般不需要 |
| 时延 | 小且稳定 | 建好后小且固定 | 较大且不固定 |
| 线路利用率 | 低 | 低 | 高 |
| 费用 | 最高（按带宽包月） | 按时长 | 最低 |
| 典型应用 | DDN、E1、SDH 专线 | **PSTN、ISDN** | X.25、FR、ATM、SMDS |

- **PSTN 模拟、ISDN 数字**；ISDN **BRI = 2B+D = 144 kbit/s**（D 16 kbit/s），**PRI = 30B+D**（E1，D 64 kbit/s）
- 分组交换四步：**切块、加头、转发、重组**；优点线路利用率高，缺点实时性较差

> **记忆口诀**
> **专线买稳定，电路交换买实时，分组交换买便宜。**

## 六、本课小结

1. 三层交换机同网段走二层；不能完全替代路由器
2. 路由表字段；选路：最长前缀 → 优先级 → 开销
3. 直连、静态、动态；IGP / EGP；RIP vs OSPF
4. 广域网：远程网、分组交换、无固定拓扑；CPE → 分界点 → 本地环路 → CO → 长途网
5. DCE 提供时钟；BRI 2B+D、PRI 30B+D；三种连接方式对比
