# Class 4：注释、页内定位与列表

## 一、HTML 注释

- 语法：`<!-- 注释内容 -->`，页面上不显示，但查看源码能看到。
- ✗ 注释不能嵌套；✗ 不要在注释里写密码。

## 二、页内定位（锚点）

```html
<a href="#ch2">跳到第二章</a>
<h2 id="ch2">第二章</h2>
```

- 入口写 `href="#id"`，目标写 `id="id"`（这里**不加 #**），两边名称必须一致。
- `id` 在同一页面内要唯一。
- 跳到其他页面的某一节：`href="page.html#ch2"`。
- `<a name="">` 是旧写法，现在用 `id`。

## 三、列表

- `<ul>` 无序列表（圆点）→ 菜单、特点
- `<ol>` 有序列表（编号）→ 步骤、排名
- 每一项写在 `<li>` 里，`<li>` 直接放在 `<ul>`/`<ol>` 中。

```html
<ul>
    <li>前端
        <ul><li>HTML</li><li>CSS</li></ul>
    </li>
</ul>
```

- 嵌套列表：把子列表放在 `<li>` 里面。
- ★ 按内容**有没有先后顺序**选列表类型，不按外观选。
