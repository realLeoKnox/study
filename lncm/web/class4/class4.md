# Class 4：HTML 注释、页内定位与列表

本节学习三件事：为源码添加说明、在页面内部跳转、用列表组织同类内容。

## 一、HTML 注释

注释写在源码中，用于解释代码，浏览器不会把它作为页面正文显示。

```html
<!-- 下面是课程目录 -->
<h2>课程目录</h2>
```

| 要点 | 说明 |
| --- | --- |
| 语法 | `<!-- 注释内容 -->` |
| 作用 | 说明结构、记录维护提示 |
| 限制 | 不要嵌套注释；注释内容中不要出现 `--` |
| 提醒 | 用户仍可查看网页源码中的注释，不要写密码等敏感信息 |

注释适合解释“这段代码为什么存在”；标签和内容本身已足够清楚时，不必逐行添加注释。

## 二、页内定位（锚点链接）

要跳到同一页面的某个位置，先给目标元素设置唯一的 `id`，再用 `href="#目标id"` 建立链接。

```html
<a href="#chapter2">跳到第二章</a>

<h2 id="chapter2">第二章</h2>
<p>第二章的内容……</p>
```

点击链接后，浏览器会尝试将 `id="chapter2"` 的元素滚动到可见位置。页面高度不足、目标已在视野内等情况，可能看不出明显滚动。

### 两个位置要对应

| 位置 | 写法 | 含义 |
| --- | --- | --- |
| 跳转入口 | `<a href="#chapter2">第二章</a>` | `#` 后写目标的 `id` |
| 跳转目标 | `<h2 id="chapter2">第二章</h2>` | 元素上设置 `id`，这里不写 `#` |

### 易错点

- `href="#chapter2"` 与 `id="chapter2"` 名称必须一致。
- 一个页面内的 `id` 应保持唯一，否则定位结果不可靠。
- `<a name="...">` 是旧式写法；新笔记和新代码优先使用任意目标元素上的 `id`。
- 需要跳到另一页面的某一节时，可写 `href="page.html#chapter2"`。

## 三、列表标签

列表用于把同类内容组织成一组。选择列表类型时，先判断**顺序是否有意义**。

| 类型 | 外层标签 | 列表项 | 适用场景 |
| --- | --- | --- | --- |
| 无序列表 | `<ul>` | `<li>` | 菜单、特点、无需排序的项目 |
| 有序列表 | `<ol>` | `<li>` | 操作步骤、排名、需要先后顺序的项目 |

### 1. 无序列表 `<ul>`

各项之间没有先后顺序，浏览器通常显示项目符号。

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

### 2. 有序列表 `<ol>`

项目按顺序排列，浏览器通常显示数字编号。

```html
<ol>
    <li>打开编辑器</li>
    <li>编写 HTML</li>
    <li>在浏览器中查看</li>
</ol>
```

`<li>` 表示一个列表项，应直接放在 `<ul>` 或 `<ol>` 内。若列表项内部还有子项目，可以在对应的 `<li>` 内再放一个列表。

```html
<ul>
    <li>前端技术
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>
```

### 注意

- “无序”表示**语义上没有先后次序**，不等于内容没有排列顺序。
- 项目符号和编号的外观可以用 CSS 调整；不要为了获得圆点或数字而选错列表类型。
- 表格、表单、列表是不同的内容结构：表格呈现行列数据，表单收集输入，列表组织项目。这里学习的是列表。

---

## 四、本节小结

1. `<!-- ... -->` 是 HTML 注释，源码可见，页面正文不显示。
2. 页内跳转依靠 `href="#id"` 与目标元素的 `id="id"` 对应。
3. `<ul>` 表示无序列表，`<ol>` 表示有序列表，两者的每一项都写在 `<li>` 中。
4. 列表类型根据内容关系选择，外观交给 CSS 调整。

## 重点掌握

能独立写出“目录链接 → 章节标题”的页内跳转，以及一份有序列表和一份无序列表。
