# Class 18：数据转换、作用域与运算符（手抄版）

## 一、字符串转数值 ★

- **`parseInt(str)`**（转整数，注意大写 `I`）：忽略前导空格；首字符非数字/正负号或空串返回 `NaN`；遇非数字字符（含 `.`）立即停止（**截断不四舍五入**）。
- **`parseFloat(str)`**（转实数）：规则同上，**第一个小数点 `.` 有效**（第二个停止），支持科学计数法。

```js
parseInt("-12.2ab");  // -12    parseInt("e3");       // NaN
parseInt("356.3");    // 356    parseInt("");         // NaN
parseFloat("-3.2a");  // -3.2   parseFloat(".2e2");   // 20
parseFloat("1.2.3");  // 1.2    parseFloat("c302");   // NaN
```

## 二、常量、变量与作用域 ★

- **命名规则**：只能以**字母、`_`、`$` 开头**，区分大小写；`let $_5n = 6` 合法，`let 2a = 3` 报错。
- **`var`**：无块级作用域（ES5 旧写法）；**`let`**：块级作用域局部变量（ES6+）；**`const`**：块级只读常量，**声明时必须赋值**，同作用域不可重赋值/重声明。

```js
if (true) { var a = 1; } console.log(a); // 1
if (true) { let b = 2; } console.log(b); // ReferenceError
```

## 三、赋值与算术运算符 ★

| 复合赋值 | 等价写法 | 算术运算符 | 作用与示例 |
| --- | --- | --- | --- |
| `x += y` / `-=` | `x = x ± y` | `%`（求余） | `100 % 6` → `4` |
| `x *= y` / `/=` | `x = x * / y` | `**`（指数） | `100 ** 2` → `10000` |
| `x %= y` | `x = x % y` | `+` / `-`（一元） | `+"12"` → `12`，`-"5"` → `-5` |
| `x **= y` | `x = x ** y` | `++` / `--` | 前置先变后用，后置先用后变 |

```js
let a = 100;
console.log(a--); // 100（随后 a 变 99）
console.log(--a); // 98（先减再输出）
```

## 四、实例：输入数字判断奇偶

```js
function panduan() {
  let num = document.getElementById("num").value; // 取值为字符串
  if (num % 2 == 0) alert("偶数");
  else alert("奇数");
}
```
