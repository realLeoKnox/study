- 回顾 JS 区分大小写、注释、常见数据类型与 `typeof` 检测。

## 一、前置回顾：基本语法与常见数据类型

JavaScript **严格区分大小写**；注释分单行注释 `//` 和多行注释 `/* ... */`。不确定某个值的类型时，用 `typeof` 检测。

> **口径说明**：本课课件沿用传统分法，将常见类型概括为 **5 种原始数据类型**（`number`、`string`、`boolean`、`undefined`、`null`）加上 `Object` 对象与 `Function` 函数；ES6+ 标准还包含 `symbol` 与 `bigint`（合称 7 种原始类型，见 Class 17）。考试与作业以老师讲授口径和课件为准。

| 分类 | 写法特征 | 示例 |
| --- | --- | --- |
| 数字（整数 / 浮点数） | 兼容正负号与科学计数法 | `12`、`-6`、`3.14`、`2e3` |
| 布尔 `boolean` | 只有真、假两个值 | `true`、`false` |
| 字符串 `string` | 单引号或双引号包裹 | `'hello'`、`"你好"` |
| 函数 `function` | 使用关键词 `function` 定义 | `function f1() { ... }` |
| 数组 | 两侧方括号 `[]`，英文逗号分隔 | `["a", "b", "c"]` |
| 对象 | 两侧大括号 `{}`，键值对逗号分隔 | `{ name: "张三", age: 18 }` |

## 二、字符串转数值：`parseInt()` 与 `parseFloat()`

网页输入框（`<input>`）读出来的值默认是**字符串**，做数值运算前常需要转换为数字。

### 1. `parseInt()`：字符串转整数

- **规则 A**：忽略字符串前面的空格，直到找到第一个非空格字符；如果第一个非空格字符不是数字字符或正负号（`+` / `-`），则返回 `NaN`（Not a Number）。
- **规则 B**：转换空字符串（或纯空格字符串）返回 `NaN`。
- **规则 C**：如果第一个字符是数字（或正负号后紧跟数字），会继续向后解析，直到字符串结束或遇到非数字字符（包括小数点 `.`）为止。

```js
console.log(parseInt("12"));      // 12
console.log(parseInt("-12.2ab")); // -12（遇到小数点停止）
console.log(parseInt("12.2"));    // 12
console.log(parseInt("a12"));     // NaN（首字符不是数字或正负号）

// class18.html 课堂测试
console.log(parseInt("356.3"));   // 356
console.log(parseInt("-6a"));     // -6
console.log(parseInt("e3"));      // NaN（字母 e 开头）
console.log(parseInt(""));        // NaN（空字符串）
```

注意函数名拼写是 `parseInt`（中间是大写字母 **`I`**，不是小写字母 `l`）。

### 2. `parseFloat()`：字符串转实数（浮点数）

- **规则 A**：基础规则同 `parseInt()`——忽略前导空格；首字符不是数字、正负号或小数点 `.`，以及空字符串时，返回 `NaN`。
- **规则 B**：字符串中的**第一个小数点 `.`** 会被当作有效小数点解析；如果后面出现第二个小数点，则视为非数字字符并停止解析（如 `parseFloat("1.2.3")` 得到 `1.2`）。
- **规则 C**：支持科学计数法（如 `.2e2` 表示 `0.2 × 10² = 20`），并始终按十进制解析；遇到无法组成有效数字的字符即停止。

```js
console.log(parseFloat("-3.2a")); // -3.2
console.log(parseFloat(".2e2"));  // 20（0.2 × 10²）
console.log(parseFloat("c302"));  // NaN
console.log(parseFloat("1.2.3")); // 1.2（第二个小数点处停止）
```

| 方法 | 目标结果 | 遇到小数点 | 遇到尾部字母 | 空字符串 |
| --- | --- | --- | --- | --- |
| `parseInt()` | 整数 | 停止解析（截断小数） | 停止解析，保留前面整数 | `NaN` |
| `parseFloat()` | 浮点数 | 第一个有效，第二个停止 | 停止解析，保留前面数值 | `NaN` |

> 补充：课堂 `class18.html` 中还用到了 `Number(num)` 在控制台观察转换结果。与 `parseInt()` / `parseFloat()` 不同，`Number()` 要求整个字符串都是合法数字（如 `Number("12a")` 为 `NaN`），且 `Number("")` 会返回 `0`。

## 三、常量、变量与作用域

### 1. 三种声明方式

| 关键字 | 所属版本 | 作用域 | 特点与要求 |
| --- | --- | --- | --- |
| `var` | ES5 及以前 | 函数 / 全局作用域 | 声明一个变量，可赋初始值；无块级作用域 |
| `let` | ES6+ | 块级作用域 | 声明块作用域内的局部变量，可赋初始值，可重新赋值 |
| `const` | ES6+ | 块级作用域 | 声明块作用域内的只读常量，**声明时必须赋值** |

### 2. 标识符（变量）命名规则

变量名属于标识符：必须以**字母**、**下划线 `_`** 或**美元符号 `$`** 开头，后续可以是字母、数字、`_` 或 `$`，且**区分大小写**，不能以数字开头，也不能使用关键词。

```js
let c_num = 5;   // 合法：字母开头，可含下划线
let $_5n = 6;    // 合法：$ 开头，可含下划线和数字
// let 2a = 3;   // 报错：不能以数字开头
```

### 3. 变量作用域（全局、局部与块级）

- **全局变量**：在函数和代码块外部声明，整个脚本范围内都可以访问。
- **局部变量**：在函数内部或代码块 `{}` 内部声明，只在对应的函数或代码块内有效。

```js
let a = 100;       // 全局变量
function f1() {
    let b = 200;   // 局部变量，仅在 f1 内有效
    console.log(b);
}
console.log(a);    // 100
f1();              // 200
```

ES5 之前没有语句块作用域概念，只能用 `var` 声明；从 ES6 开始，使用 `let` / `const` 声明的标识符只能在所在代码块 `{}` 内使用：

```js
if (true) {
    var a = 1;
}
console.log(a); // 1（var 穿透了 if 语句块）

if (true) {
    let b = 2;
}
console.log(b); // ReferenceError: b is not defined
```

### 4. 常量 `const`

ES6 起用 `const` 声明只读常量：**声明时必须赋初始值**，之后在同一作用域内既不能重新赋值，也不能重复声明，否则报错。

```js
const PI = 3.1415926;
console.log(PI);
// PI = 3.14;    // TypeError：常量不能重新赋值
// const X;      // SyntaxError：声明时必须赋值
```

## 四、赋值运算符

最简单的赋值运算符是 `=`，把右边的值赋给左边；常见复合赋值简写如下：

| 名称 | 简写操作符 | 等价含义 | 课堂示例（每次重置 a = 100） |
| --- | --- | --- | --- |
| 赋值 | `x = y` | `x = y` | `a = 100` → `100` |
| 加法赋值 | `x += y` | `x = x + y` | `a += 100` → `200` |
| 减法赋值 | `x -= y` | `x = x - y` | `a -= 25` → `75` |
| 乘法赋值 | `x *= y` | `x = x * y` | `a *= 2` → `200` |
| 除法赋值 | `x /= y` | `x = x / y` | `a /= 25` → `4` |
| 求余赋值 | `x %= y` | `x = x % y` | `a %= 6` → `4` |
| 求幂赋值 | `x **= y` | `x = x ** y` | `a **= 2` → `10000` |

> 课堂代码 `class18.html` 第 60 行写的是 `console.log(a % 6)`，它会输出余数 `4`，但**不会**修改 `a` 本身；写成 `a %= 6` 才会把余数写回 `a`。

## 五、算术运算符

除了标准的加 `+`、减 `-`、乘 `*`、除 `/` 之外，JavaScript 还提供以下常用算术运算符：

| 名称与符号 | 描述 | 示例与结果 |
| --- | --- | --- |
| 求余 `%` | 返回两数相除的余数 | `100 % 6` → `4`；`8 % 2` → `0` |
| 自增 `++` | 操作数加 1（前置先加后用，后置先用后加） | `let x = 3; ++x` → `4` |
| 自减 `--` | 操作数减 1（前置先减后用，后置先用后减） | `let x = 3; x--` → `3`（随后 `x` 变 `2`） |
| 一元负值符 `-` | 取相反数；作用于数字字符串时先转数值再取负 | `let x = 3; -x` → `-3`；`-"5"` → `-5` |
| 一元正值符 `+` | 尝试把操作数转换为数值 | `+"12"` → `12`；`+true` → `1` |
| 指数运算符 `**` | 计算底数的指数次幂 | `2 ** 3` → `8`；`100 ** 2` → `10000` |

### 重点区分：前置自减 `--a` 与后置自减 `a--`

对照 `class18.html` 最后三行，一步步跟踪变量 `a` 的变化：

```js
let a = 100;
console.log(a--); // 先返回旧值 100 输出，再把 a 减 1（此时 a = 99）
console.log(--a); // 先把 a 减 1（变为 98），再返回新值 98 输出
```

- **后置 `a++` / `a--`**：表达式的值是**变化之前**的旧值，然后变量再加 1 或减 1。
- **前置 `++a` / `--a`**：先把变量加 1 或减 1，表达式的值是**变化之后**的新值。

## 六、课堂实例：输入数字判断奇偶

课堂文件 `class18.html` 把输入框、按钮点击事件与 `%` 求余运算符结合起来：

```html
<p>请输入数字：<input id="num" type="text"></p>
<p><input type="button" value="判断奇偶" onclick="panduan()"></p>
<script>
  function panduan() {
    let num = document.getElementById("num").value;
    console.log(Number(num));
    if (num % 2 == 0) {
      alert("偶数");
    } else {
      alert("奇数");
    }
  }
</script>
```

执行流程：

1. 用户在 `<input id="num">` 中输入内容后，点击“判断奇偶”按钮触发 `panduan()`。
2. `document.getElementById("num").value` 读取输入内容（得到的是**字符串**）。
3. `console.log(Number(num))` 在控制台打印转成数字后的值，方便调试观察。
4. `num % 2 == 0` 计算除以 `2` 的余数（`%` 运算会自动尝试把数字字符串转为数值）：余数为 `0` 弹窗“偶数”，否则弹窗“奇数”。

> **边界提醒**：如果输入框为空直接点击，`"" % 2` 会得到 `0` 而提示“偶数”；如果输入 `"abc"`，`NaN % 2` 得 `NaN`，条件为假会落入 `else` 提示“奇数”。实际工程中通常先校验输入不为空且为有效整数。

## 常见错误

1. 把 `parseInt()` 拼错成 `parselnt()`（把大写字母 `I` 打成小写字母 `l`），运行时报 `ReferenceError`。
2. 误以为 `parseInt("356.8")` 会四舍五入得到 `357`；实际遇到小数点就停止解析，直接截断得 `356`。
3. 误以为 `parseInt("a12")` 能跳过开头字母取到 `12`；实际只要第一个非空格字符不是数字或正负号，直接返回 `NaN`。
4. 用数字开头命名变量（如 `let 2a = 3`），或声明 `const` 常量时不赋初始值，都会直接触发语法错误。
5. 混淆 `a--` 与 `--a` 的输出值，或者把 `a % 6`（只计算不赋值）误当成 `a %= 6`（计算并写回 `a`）。
6. 在 `if (true) { let b = 2; }` 代码块外部访问 `b`，触发 `ReferenceError`；忘记 `let` / `const` 具有块级作用域。

## 本课小结

`parseInt()` 和 `parseFloat()` 负责按前缀规则把字符串转为整数和浮点数；`var`、`let`、`const` 决定了变量/常量的作用域与可修改性；复合赋值运算符和算术运算符（尤其是 `%`、`**` 与前后置 `++`/`--`）构成了页面数值计算的基础，奇偶判断案例正是把输入读取、取余判断与条件分支串成闭环。
