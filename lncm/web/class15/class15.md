## 二、CSS 背景

| 属性 | 作用 | 取值 |
| --- | --- | --- |
| `background-color` | 背景颜色 | 颜色值 |
| `background-image` | 背景图片 | `url("路径")` |
| `background-repeat` | 是否平铺 | `repeat`（默认）、`no-repeat`、`repeat-x`、`repeat-y` |
| `background-position` | 背景位置 | 水平 + 垂直，可以写关键字、百分比、像素 |

### 案例一：`class15.html`

```css
div{
  width: 900px;
  height: 600px;
  border: 1px solid #f000;
  background-color: #f28;
  background-image: url("./2026-11-05 18.48.28.jpg");
  background-repeat: no-repeat;
  background-position: 50% 50%;     /* center center */
}
```

页面里只有一个空的 `div`，把一张图片放在这个 900×600 的粉色盒子正中间。

### 1. 逐行分析

**① `background-color: #f28`**
3 位的十六进制是**简写**，每一位重复一次：`#f28` = `#ff2288`。实测颜色是 `rgb(255, 34, 136)`（粉红色）。

**② `border: 1px solid #f000`**
这行有一个容易忽略的地方：`#f000` 是**4 位十六进制**，最后一位是透明度（alpha），`0` 表示完全透明。实测边框颜色是 `rgba(255, 0, 0, 0)`，**边框是透明的**。

- 透明边框**照样占位**：盒子实际大小是 **902 × 602**（900 + 1 + 1，600 + 1 + 1），不是 900 × 600。
- 背景默认画到边框的外沿，所以透明的边框那一圈会**露出粉色背景**（实测盒子最外一圈像素就是粉色）。

> 老师可能想写的是 `#f00`（红色），写成了 `#f000`，是不是笔误课上没确认。按代码实际效果，边框是透明的。

**③ `background-image: url("./2026-11-05 18.48.28.jpg")`**
这张图是 640 × 640 的卡通图。文件名里有空格和点，所以 `url()` 里要用**引号**包起来。老师的示例（`example.md`）里换成了 `./icon_qq.png`，代码结构一样，只是换了一张图片。

**④ `background-repeat: no-repeat`**
不平铺，图片只放一张。放不满的地方会**露出背景色**（实测盒子左右两侧是粉色）。

**⑤ `background-position: 50% 50%`**
水平 50%、垂直 50%，等价于 `center center`，图片居中。

### 2. 百分比位置是怎么算的

```
偏移量 = （盒子大小 − 图片大小）× 百分比
```

这里盒子的内边距区域是 900 × 600，图片是 640 × 640：

- 水平：(900 − 640) × 50% = **130px**，图片左边离盒子 130px，左右留白一样。
- 垂直：(600 − 640) × 50% = **−20px**，图片比盒子还高，所以**上下各被裁掉 20px**。

实测几种写法，图片左上角相对盒子的偏移（用像素逐点比对得到，误差为 0）：

| `background-position` | 图片左上角 (x, y) | 说明 |
| --- | --- | --- |
| `50% 50%`（课堂写法） | (130, −20) | 居中，上下各裁 20px |
| `0 0` | (0, 0) | 贴左上角 |
| `100% 100%` | (260, −40) | 贴右下角，上面被裁 40px |
| `center top` | (130, 0) | 水平居中、贴顶部（= `50% 0%`） |
| `20px 30px` | (20, 30) | 像素值：从左上角往右 20、往下 30 |

**记忆：**

- 第一个值是**水平**，第二个值是**垂直**。
- 关键字对应百分比：`left` = 0%，`center` = 50%，`right` = 100%；`top` = 0%，`bottom` = 100%。
- 只写一个值时，另一个方向默认是 `center`（这是 CSS 规范的规定，课上没有单独验证）。

### 3. 平铺 `background-repeat`

| 取值 | 效果 |
| --- | --- |
| `repeat`（默认） | 横向、纵向都平铺 |
| `no-repeat` | 不平铺，只放一张 |
| `repeat-x` | 只沿**水平**方向平铺 |
| `repeat-y` | 只沿**垂直**方向平铺 |

实测（图片 640×640，盒子内边距区域 900×600）：

| 取值 | 盒子左右两侧 | 现象 |
| --- | --- | --- |
| `no-repeat` | 露出粉色背景 | 只有中间一张 |
| `repeat-x` | 被图片铺满 | 横向重复了 |
| `repeat-y` | 露出粉色背景 | **和 `no-repeat` 看不出区别** |
| `repeat` | 被图片铺满 | 横向重复 |

★ **`repeat-y` 在这个例子里没有效果**：图片高 640，比盒子的 600 还高，纵向本来就放不下第二张，所以看起来和不平铺一样。要看到纵向平铺，图片必须**比盒子矮**。

## 三、案例二：`hebing.html`（header + banner + footer 合并）

把前几节课的成果拼成一个完整页面：

```
body
├─ .header           黑色导航栏（Class 13 的 header）
├─ .content
│   └─ .con_cen      980px 版心，居中
│       └─ <img>     banner 大图 kv2.jpg
└─ .footer           页脚（Class 14 的 footer，含两个二维码）
```

### 1. 新增的样式

```css
/* 3.content 部分 */
.con_cen{
  width: 980px;
  margin: 0 auto;      /* 版心居中 */
}
.con_cen img{
  width: 980px;        /* 图片宽度 = 版心宽度 */
}
```

### 2. 合并是怎么做的

- header 和 footer 的样式**原样**拼进同一个 `<style>`，`<body>` 里把三块内容从上到下摆好，类名没有冲突。
- `li { float: left; list-style: none; }` 在 header 和 footer 的样式里各写了一遍，内容一样，重复无害。
- `body { margin: 0 }` 是 footer 带来的，它同样让 header 和 banner 贴到页面边缘（不再有 8px 空白）。
- 素材路径是 `../../sucai/images/…`：`hebing.html` 在 `class15/hebing/` 里，`../../` 回到 `class` 目录，所以素材统一放在 `class/sucai/images/`。

### 3. 实测：banner 的尺寸

| 项目 | 实测 | 怎么算 |
| --- | --- | --- |
| banner 原图 | 1440 × 500 | — |
| 显示大小 | 980 × 340.3 | 只设了 `width: 980px`，高度按比例自动算：500 × 980 ÷ 1440 = 340.28 |
| `.content` 高度 | 344.3 | 340.3 + **4px 缝隙** |
| `.footer` 起始位置 y | 441.3 | 85（header）+ 344.3 + 12（`.footer` 的 `margin-top`） |

★ **只设宽度，高度会按比例自动缩放**，图片不会变形。想变形才同时设宽高。

★ **图片下面多出 4px 缝隙**：`<img>` 默认是行内元素，底部要给文字基线留空隙，这个现象和 Class 14 页脚里的二维码是同一回事。给 `img` 加 `display: block` 后，`.content` 的高度就是 340.3。课堂代码没有加，了解即可。

### 4. 二维码白边

合并时页脚的二维码带着 Class 14 遗留的白边问题，已经修好，原因和修改见 [Class 14 笔记第八节](../class14/class14.md)。`hebing.html` 的 CSS 里也留了注释。

## 四、易错点

1. **`#f000` 是透明色**：4 位十六进制最后一位是透明度，`0` 是全透明。边框不显示但**仍然占位**，盒子会多出 2px。
2. **`url()` 里文件名有空格要加引号**：路径里有空格、特殊字符时，用引号包起来最保险。
3. **百分比位置的算法**：`(盒子 − 图片) × 百分比`，图片比盒子大时偏移量是负数，会被裁掉一部分。
4. **`repeat-y` 看不到效果**：图片比盒子高时，纵向放不下第二张，必须图片比盒子矮才能看出平铺。
5. **背景色在图片后面**：不平铺或图片没盖满的地方，才会露出背景色。
6. **`<img>` 底部有 4px 缝隙**：行内元素的通病，用 `display: block` 解决。
7. **只设宽度，高度自动按比例**，图片不变形。
8. **相对路径 `../../`**：每个 `../` 往上一级目录，数清楚当前文件在哪一层。
