# Class 6：网页图片与多媒体

上节课用表格组织数据；表格单元格和普通段落中都可以放图片。本节学习如何让网页显示图片、播放音频和视频，并区分“文件地址”与“内容说明”。

## 一、图像标签 `<img>`

`<img>` 是空元素，没有结束标签。最常用的写法是：

```html
<img src="photo.jpg" alt="校园操场的照片">
```

| 属性 | 作用 | 记忆要点 |
| --- | --- | --- |
| `src` | 指定图片文件地址 | 路径要相对于当前 HTML 文件正确填写 |
| `alt` | 图片的文字替代内容 | 描述图片传达的信息 |
| `width`、`height` | 指定图片显示尺寸 | HTML 属性的数值通常以 CSS 像素计 |
| `title` | 提供附加提示 | 不能代替 `alt`，也不宜承载关键信息 |

图片无法加载时，`alt` 可作为替代文字；使用读屏工具的人也需要它理解图片。纯装饰图片可写 `alt=""`，有信息的图片要写具体内容，避免只写“图片”。

### 路径与尺寸示例

假设 HTML 与图片在同一文件夹：

```html
<img src="./photo.jpg" alt="课堂板书" width="300" height="200">
```

`./` 表示当前文件夹，与 Class 3 的相对链接规则相同。`width`、`height` 最好与图片实际宽高比一致；需要自适应布局时，再用 CSS 控制显示尺寸。

### 易错点

- 图片文件名、扩展名和路径必须与实际文件一致。
- `alt` 说明的是图片内容或作用，不是鼠标悬停提示。
- 不要把重要文字只做成图片；文字仍应尽量保留为真正的文本。

## 二、常见网页图片格式

| 格式 | 主要特点 | 常见用途 |
| --- | --- | --- |
| JPEG / JPG | 有损压缩，不支持透明 | 照片 |
| PNG | 无损，支持透明 | 截图、需要清晰边缘的图 |
| GIF | 颜色较少，可做简单动画 | 小型动图 |
| WebP | 可有损或无损，支持透明和动画 | 网页图片 |
| SVG | 矢量图，缩放仍清晰 | 图标、Logo、线条图 |
| AVIF | 可有损或无损，通常压缩效率较高 | 网页照片或插图 |

**补充：**APNG 是支持动画的 PNG 扩展，不能把“PNG 绝对不能动”当作规则。BMP 文件通常较大，不作为网页图片的常用选择。选格式时看内容、画质、文件大小和目标浏览器支持情况。

## 三、音频与视频

`<audio>` 和 `<video>` 都是成对标签。`src` 指向媒体文件，`controls` 让用户看到播放控件。

```html
<audio src="lesson.mp3" controls>
    你的浏览器不支持音频播放。
</audio>

<video src="demo.mp4" controls width="400">
    你的浏览器不支持视频播放。
</video>
```

| 属性 | 作用 | 适用标签 |
| --- | --- | --- |
| `controls` | 显示播放、暂停等控件 | 音频、视频 |
| `autoplay` | 请求自动播放 | 音频、视频 |
| `muted` | 初始静音 | 音频、视频 |
| `loop` | 播放结束后循环 | 音频、视频 |
| `width`、`height` | 设置视频显示尺寸 | 视频 |
| `poster` | 视频播放前显示的封面图 | 视频 |

`controls`、`autoplay`、`muted`、`loop` 是布尔属性：写上即表示开启，不必写成 `="true"`。浏览器可能阻止带声音的自动播放；即使写了 `autoplay`，也不能保证一定播放。教学示例优先提供 `controls`，让用户自行操作。

### 多种媒体文件（了解）

同一段媒体有不同格式时，可在 `<audio>` 或 `<video>` 中放多个 `<source>`，让浏览器选择支持的文件。文件扩展名相同也可能使用不同编码，因此播放兼容性还取决于编码格式。

```html
<video controls width="400">
    <source src="demo.webm" type="video/webm">
    <source src="demo.mp4" type="video/mp4">
    你的浏览器不支持视频播放。
</video>
```

旧资料中还会看到 `<embed>`。对普通音视频，优先使用有明确播放语义和控制属性的 `<audio>`、`<video>`。

## 四、本节小结

1. `<img>` 显示图片；`src` 指路径，`alt` 提供有意义的文字替代。
2. Class 3 学到的相对路径规则同样适用于图片和媒体文件。
3. JPEG、PNG、GIF、WebP、SVG、AVIF 各有适用场景。
4. `<audio>`、`<video>` 播放媒体，`controls` 让用户控制播放。
5. `autoplay` 只是播放请求，实际效果受浏览器策略影响。

## 与下一课相连

图片和视频负责展示内容；如果要让用户**输入文字、选择选项或上传图片**，下一课需要使用表单。上传图片用 `<input type="file">`，显示图片则用 `<img>`。

## 重点掌握

能正确填写图片路径与 `alt`，并能区分媒体展示标签和表单中的文件上传控件。
