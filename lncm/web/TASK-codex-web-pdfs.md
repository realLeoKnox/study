## 0. 我的笔记是什么（先看这条）

课堂实时跟进的 Markdown，基本全是提纲、要点，像写提示词一样，本身就不完整。**笔记写得短、写得像清单，不是漏记**，不要拿它当完整课堂记录去补写、扩写或重新排版。

主线之外的判断顺序：

1. **笔记里有的，基本就是课堂主线。** 正常篇幅写，不要删减。
2. **只有代码文件里有、笔记里没提的，大概率是我自己额外引入的，或者课堂不侧重的。** 这种轻轻提一嘴，不展开成大段落，也不写进「本课目标」「重点掌握」「自测题」。
3. **如果我真把额外的东西写进了笔记，我会自己加注释写明。** 看到这类注释以它为准。
4. 判断不了的，按「主线之外」处理，宁少勿多。

本任务以格式和 PDF 为主，**不要新增、改写、重排任何一课的知识内容**。
