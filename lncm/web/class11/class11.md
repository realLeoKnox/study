# Class 11：文章页面综合练习

Class 10 已学会文章容器、图片和正文的排版。本节把这些方法用于更完整的新闻页面：**标题 → 发布时间与来源 → 头图 → 声明 → 正文 → 强调内容**。重点是把 HTML 的结构和 CSS 的样式对应起来。

## 一、先拆解课堂页面

| 页面部分 | 课堂示例中的做法 | 主要知识点 |
| --- | --- | --- |
| 整篇内容 | `.content` 限定宽度并居中 | `width`、`margin` |
| 主标题 | `h1` 设置较大字号 | 标题语义、`font-size` |
| 时间和来源 | `.xiao_bt` 使用较小灰字 | 辅助信息的视觉层级 |
| 评论数 | `.color_red` 改变颜色和间距 | 类选择器、`color`、`margin` |
| 头图 | `<img>` 显示 GIF | 图片路径与 `alt` |
| 声明框 | `.shengming` 设置背景与内边距 | 背景、盒模型 |
| 结尾强调 | `.last_cu` 加粗 | `font-weight` |

浏览页面时，先问“这一块是什么内容”，再问“它需要什么样式”。这就是前面 HTML 课与 CSS 课的连接点。

---

## 二、搭建文章的 HTML 结构

```html
<article class="article">
    <header>
        <h1>文章标题</h1>
        <p class="meta">发布时间 · 来源</p>
    </header>

    <img class="cover" src="cover.gif" alt="文章头图的具体内容">
    <p class="notice">转载与来源说明。</p>
    <p>正文第一段。</p>
    <p class="ending">正文结尾。</p>
</article>
```

`<article>` 包住可独立阅读的文章，`<header>` 放标题和元信息。各段正文分别放在 `<p>` 中；`class` 只负责标记需要共用样式的元素，不改变标签本身的语义。

---

## 三、给内容建立清晰的视觉层级

```css
.article {
    max-width: 600px;
    margin: 0 auto;
    padding: 0 16px;
    box-sizing: border-box;
    font-size: 16px;
    line-height: 1.6;
}
.article h1 { font-size: 2rem; }
.meta { color: #666; font-size: 14px; }
.cover { display: block; max-width: 100%; height: auto; }
.ending { font-weight: 700; }
```

| 属性 | 回忆它解决的问题 |
| --- | --- |
| `max-width` | 限定文章最大宽度，又允许窄屏缩小 |
| `margin: 0 auto` | 让文章容器水平居中 |
| `padding` | 在容器内部留白 |
| `font-size` | 设定字号层级 |
| `line-height` | 设定多行文字的行高 |
| `max-width: 100%` | 让图片不超过父容器 |

`font-weight: 700` 是常见的加粗字重值，效果接近 `bold`。需要表达内容的重要性时，仍要根据 Class 3 的规则选用 `<strong>`；单纯视觉加粗可用 CSS。

## 四、声明框与盒模型

课堂示例用浅灰色背景突出转载声明。盒子从内到外可以记为：**内容 → 内边距 padding → 边框 border → 外边距 margin**。

```css
.notice {
    background-color: #eee;
    padding: 16px;
    margin: 20px 0;
    line-height: 1.6;
}
```

`padding` 是文字到背景边缘的距离；`margin` 是声明框到周围内容的距离。若只想给内容留空间，通常不必写固定 `height`：文字换行或字号变大时，固定高度可能使内容溢出。

### 对照课堂写法

课堂 `.shengming` 同时写了 `height: 100px` 和 `padding: 18px`。默认盒模型下，高度只计算内容区，实际占据的高度还要加上下内边距；因此不能把它简单理解成“整个框恰好高 100px”。

## 五、页面检查清单

1. **结构：**只有一个清楚的文章主标题；每段 `<p>` 正确闭合。
2. **语言：**中文页面使用合适的 `lang`，例如 `<html lang="zh-CN">`。
3. **图片：**路径能找到文件；传达信息的图片写有意义的 `alt`。
4. **文字：**标题、元信息、正文有层级；重要内容不要只靠颜色区分。
5. **尺寸：**容器和图片能在较窄窗口中缩小；正文和说明文字仍容易阅读。
6. **交互：**若“评论数”可点击，应使用链接等可交互元素，不能只给 `<span>` 改颜色。

课堂文件中的 `lang="en"` 与中文内容不一致，头图的 `alt` 为空，文章宽度固定为 600px；这些都可作为检查新页面时的改进点。课堂示例本身仍可用来观察样式效果。

## 六、把整套课程串起来

| 阶段 | 学到的内容 | 在文章页中的位置 |
| --- | --- | --- |
| Class 1–4 | 标题、段落、链接、列表 | 组织文字与导航 |
| Class 5 | 表格 | 展示需要行列对照的数据 |
| Class 6 | 图片与媒体 | 头图、视频和说明 |
| Class 7–8 | 表单 | 搜索、评论、报名等用户输入 |
| Class 9 | CSS 选择器和文字样式 | 给不同内容应用样式 |
| Class 10–11 | 容器、图片、留白与综合排版 | 完成可阅读的页面 |

## 本节小结

写页面的顺序是：**先确定内容和语义 → 写出 HTML 结构 → 用 CSS 设置视觉层级 → 检查窄屏与可访问性**。修改外观时，尽量复用类；发现结构或文字含义不对时，先修改 HTML。

## 重点掌握

能看着文章截图拆出标题、元信息、图片、声明和正文，并能为它们选择合适的 HTML 标签与 CSS 样式。
