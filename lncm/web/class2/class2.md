# Class 2：HTML 文本与基础布局标签

本节围绕“标题、段落、空白字符、容器”复习 HTML 的基础写法。记笔记时要同时记住：**标签表达什么含义，以及浏览器默认如何显示它。**

## 一、标题标签 `<h1>` ～ `<h6>`

标题有六个级别，数字越小，标题层级越高。标题层级应反映内容结构，不应只凭默认字号选择。

| 标签 | 表示的层级 | 常见用途 |
| --- | --- | --- |
| `<h1>` | 最高级标题 | 页面或文章的主标题 |
| `<h2>` | 二级标题 | 主标题下的大章节 |
| `<h3>` ～ `<h6>` | 逐级降低 | 更细的小节 |

```html
<h1>HTML 学习笔记</h1>
<h2>第一章：文本标签</h2>
<h3>1.1 标题标签</h3>
```

### 注意

- 通常为页面安排一个清晰的主标题；HTML 本身并不禁止出现多个 `<h1>`。
- 不要为了让字变大而使用标题标签；只需改变外观时应使用 CSS。

---

## 二、段落、换行与主题分隔

| 标签 | 作用 | 写法 | 适用场景 |
| --- | --- | --- | --- |
| `<p>` | 表示一个段落 | `<p>内容</p>` | 正文、说明文字 |
| `<br>` | 在当前内容中换行 | `<br>` | 地址、诗歌等需要明确断行的短文本 |
| `<hr>` | 表示主题转换或内容分隔 | `<hr>` | 两个主题之间 |

```html
<p>这是第一段。</p>
<p>这是第二段，<br>这里仍属于第二段。</p>
<hr>
<p>下面开始另一个主题。</p>
```

### 易错点

- 两段正文用两个 `<p>`，不要连续使用 `<br>` 代替段落。
- `<br>`、`<hr>` 是空元素，不需要写结束标签。
- `<p>` 中不能放 `<div>`、标题等块级结构；需要分区时在段落外使用容器。

---

## 三、HTML 中的空格与换行

普通文本中的连续空格、制表符和源码换行通常会被浏览器折叠；源码排成多行，不代表页面会按相同方式换行。

```html
<p>春眠不觉晓，
    处处闻啼鸟。</p>
```

上例在默认显示下不会因为源码换行而分成两行。若内容确实需要断行，可在相应位置写 `<br>`。

### `&nbsp;` 与 `<pre>`

| 写法 | 作用 | 何时使用 |
| --- | --- | --- |
| `&nbsp;` | 插入一个不换行空格 | 少量需要保持在同一行的空白 |
| `<pre>…</pre>` | 保留文本中的空格和换行 | 代码片段、需要原样排版的文字 |

```html
<p>HTML&nbsp;基础</p>
<pre>
第一行
    缩进后的第二行
</pre>
```

`<pre>` 默认常以等宽字体显示，并保留空白；它不会自动把其中的 HTML 标签当作可见代码。展示代码时可配合 `<code>`，并将代码里的 `<` 写成 `&lt;`。

### 记忆对比

`<p>` 表示**段落语义**；`<br>` 表示**在当前内容中换行**；`<pre>` 表示**保留原始排版**。不要仅为凑出视觉间距而滥用这些标签。

## 四、通用容器：`<div>` 与 `<span>`

两者本身没有特定语义，常用来组织内容并配合 CSS 设置样式。若内容有明确含义，应优先考虑合适的语义标签。

| 对比项 | `<div>` | `<span>` |
| --- | --- | --- |
| 默认显示 | 块级，通常从新的一行开始 | 行内，通常接在文字中 |
| 常见用途 | 划分页面区域、包裹一组元素 | 包裹一小段文字或行内内容 |
| `width`、`height` | 默认可以设置 | 默认的行内显示方式下通常不起作用 |
| 示例 | 卡片区域、内容分组 | 局部文字样式 |

```html
<div class="card">
    <p>这是一张<span class="important">重要</span>卡片。</p>
</div>
```

```css
.card { width: 200px; border: 1px solid gray; }
.important { color: red; }
```

这里的 `class` 是**属性名**，`card` 和 `important` 是自定义类名；`<class>`、`<id>` 都不是 HTML 标签。

### 注意

- “块级”和“行内”描述的是**默认显示方式**，CSS 可以改变它们。
- `<span>` 适合包裹行内内容；不要把 `<div>` 等块级结构放进 `<span>`。
- 页面中有导航、文章等明确结构时，可进一步学习 `<nav>`、`<article>` 等语义元素。

---

## 五、本节小结

1. `<h1>` ～ `<h6>` 表示标题层级，不能只当作调字号的工具。
2. `<p>` 表示段落，`<br>` 表示段内换行，`<hr>` 表示主题分隔。
3. 普通文本的连续空白通常会折叠；`<pre>` 能保留原始空白。
4. `<div>` 默认是块级容器，`<span>` 默认是行内容器。
5. `class` 和 `id` 是属性；标签的语义与默认样式是两个不同问题。

## 重点掌握

先根据内容含义选标签，再使用 CSS 调整外观。
