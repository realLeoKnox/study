# Class 2：HTML 文本与基础布局标签（复习课）

> 标题、`<p>`/`<br>`/`<hr>`、`<pre>`、`<div>`/`<span>` 的基本用法同 Class 1，本页只记新增的要点。

## 一、标题

- HTML 不禁止多个 `<h1>`，但通常一个页面只安排一个主标题。
- ✗ 不要为了让字变大而用标题，改外观用 CSS。

## 二、段落与换行的易错点

- 两段正文用两个 `<p>`，✗ 不要连续写 `<br>` 来代替段落。
- `<br>`、`<hr>` 是**空元素**，不写结束标签。
- `<p>` 里 ✗ 不能放 `<div>`、标题等块级元素。

## 三、空白

- `&nbsp;` 用于少量不换行空格；`<pre>` 用于需要原样排版的内容。
- 在 `<pre>` 中展示代码时，`<` 要写成 `&lt;`。
- 区分：`<p>` 是段落语义，`<br>` 是段内换行，`<pre>` 是保留排版。

## 四、容器与 class

```html
<div class="card">
    <p>这是<span class="important">重要</span>内容</p>
</div>
```

- `class` 是**属性**，`card` 是自定义类名；✗ `<class>`、`<id>` 不是标签。
- 块级和行内是**默认**显示方式，可以用 CSS 改变。
- ✗ 不要把 `<div>` 放进 `<span>`。

★ 重点：先按内容含义选标签，再用 CSS 调外观。
