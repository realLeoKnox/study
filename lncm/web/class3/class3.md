# Class 3：文本格式化与超链接

本节学习文字的语义标记，以及用 `<a>` 在页面之间建立链接。选择标签时，先判断文字要表达的含义，再考虑视觉效果。

## 一、常见文本格式化标签

| 标签 | 主要含义 | 默认外观（可被 CSS 修改） |
| --- | --- | --- |
| `<strong>` | 内容具有较强的重要性 | 通常加粗 |
| `<em>` | 语气上的强调 | 通常倾斜 |
| `<b>` | 吸引注意，但不表示额外的重要性 | 通常加粗 |
| `<i>` | 与正文语气不同的文字，如术语、外语短语 | 通常倾斜 |
| `<u>` | 非文字性质的标注，如专有名词标记 | 通常带下划线 |
| `<s>` | 内容已不准确或不再适用 | 通常带删除线 |
| `<del>` | 文档中被删除的内容 | 通常带删除线 |

```html
<p><strong>注意：</strong>提交前请保存文件。</p>
<p>这一步<em>尤其</em>重要。</p>
<p>原价 <s>99 元</s>，现价 79 元。</p>
```

### 容易混淆的几组

- `<strong>` 与 `<b>`：前者强调**重要性**；后者只让某段文字**受到注意**，不提高其重要程度。
- `<em>` 与 `<i>`：前者强调**语气**；后者标记与正文有所区分的文字。若只是想加粗、倾斜或加下划线，使用 CSS 更合适。
- `<s>` 与 `<del>`：前者表示内容**不再适用**，后者表示内容在**编辑过程中被删除**。

`<u>` 的下划线容易被误认为超链接，因此普通页面中应谨慎使用。

---

## 二、超链接标签 `<a>`

`<a>` 用于创建通往网页、文件或页面内位置的链接。常用语法：

```html
<a href="https://example.com/">访问示例网站</a>
```

`href` 指定目标地址；有有效目标地址的 `<a>` 才能作为普通超链接使用。链接文字应说明目标，例如“查看课程安排”，便于读者和辅助技术理解。

### 常见属性

| 属性 | 作用 | 示例 |
| --- | --- | --- |
| `href` | 指定链接目标 | `href="about.html"` |
| `target="_blank"` | 通常在新标签页打开 | `target="_blank"` |
| `rel="noopener noreferrer"` | 新标签页链接的安全与隐私设置 | `rel="noopener noreferrer"` |

```html
<a href="https://example.com/" target="_blank" rel="noopener noreferrer">
    查看示例网站
</a>
```

默认情况下，普通链接在当前标签页打开。新标签页是否开启及如何呈现，还可能受浏览器和用户设置影响。

## 三、绝对地址与相对地址

**绝对 URL** 包含协议和域名，适合链接外部网站：

```html
<a href="https://example.com/news.html">查看新闻</a>
```

**相对地址** 以当前文档所在位置为参照，适合链接同一网站中的文件。假设当前文件是 `class/class3/class3.html`：

| 写法 | 指向哪里 |
| --- | --- |
| `intro.html` | 当前 `class3` 文件夹中的文件 |
| `pages/intro.html` | 当前文件夹下 `pages` 中的文件 |
| `../class4/class4.html` | 返回上一级 `class`，再进入 `class4` |
| `../../index.html` | 返回上两级，找到 `index.html` |

`./` 表示当前目录，`../` 表示上一级目录。相对地址会随当前文件位置改变，因此移动 HTML 文件后要检查链接。

### 特别注意 `href="#"`

`#` 表示指向当前页面顶部附近的空片段，点击后可能让页面回到顶部。它不是“空标签”，也不适合作为暂未确定目标的最终链接。目标尚未确定时，笔记或草稿中可先写明待补地址；正式页面应填入真实地址，或暂时不创建链接。

---

## 四、本节小结

1. `<strong>`、`<em>` 侧重内容含义，默认加粗或倾斜只是浏览器的表现。
2. `<b>`、`<i>`、`<u>`、`<s>` 也有各自用途，不能只按外观互换。
3. `<a href="地址">文字</a>` 是创建普通超链接的基本格式。
4. 外部网站常用完整 URL；同一项目内的页面常用相对地址。
5. 使用新标签页时可配合 `rel="noopener noreferrer"`，并写清楚链接指向什么。

## 重点掌握

能解释“语义标签与视觉样式的区别”，并能根据当前文件的位置正确写出相对链接。
