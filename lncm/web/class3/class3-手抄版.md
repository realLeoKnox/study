# Class 3：文本格式化与超链接

## 一、文本格式化标签

- `<strong>` — 重要（加粗）　　`<b>` — 引起注意，不表示重要（加粗）
- `<em>` — 语气强调（倾斜）　　`<i>` — 术语、外语（倾斜）
- `<s>` — 内容不再适用（删除线）　`<del>` — 编辑时删除的内容（删除线）
- `<u>` — 标注（下划线），容易被误认成链接，少用

★ `<strong>`/`<em>` 表示**含义**；只想加粗、倾斜时用 CSS。

```html
<p>原价 <s>99 元</s>，现价 79 元</p>
```

## 二、超链接 `<a>`

```html
<a href="https://example.com/" target="_blank" rel="noopener noreferrer">示例网站</a>
```

- `href` — 链接目标（必须写）
- `target="_blank"` — 在新标签页打开
- `rel="noopener noreferrer"` — 配合新标签页使用的安全设置
- 链接文字要说明目标，如“查看课程安排”。

## 三、绝对地址与相对地址

- 绝对地址：带协议和域名，用于外部网站，如 `https://example.com/a.html`
- 相对地址：以**当前文件位置**为起点，用于站内页面
  - `./` 表示当前目录　　`../` 表示上一级目录
  - 例如当前在 `class/class3/`：`../class4/class4.html`

✗ `href="#"` 会回到页面顶部，不是“空链接”。
✗ 移动 HTML 文件后，相对链接要重新检查。
