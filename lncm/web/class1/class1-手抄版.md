# Class 1：HTML 基础标签

## 一、标题 `<h1>`～`<h6>`

- 共 6 级，`<h1>` 最高、`<h6>` 最低。
- 作用是表示内容的**层级结构**，不只是改字号。

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
```

## 二、段落、换行、分隔线

- `<p>` — 段落，成对标签，段与段之间有间距
- `<br>` — 换行，单标签，**不产生新段落**
- `<hr>` — 水平分隔线，单标签，分隔不同主题

```html
<p>第一行<br>第二行</p>
<hr>
```

## 三、空格与换行的折叠

- 源码中连续的空格和换行，浏览器会**折叠成一个空格**。
- 想要不折叠的空格：`&nbsp;`（不换行空格）。
- 想要换行：`<br>`；想要保留原排版：`<pre>`。

## 四、`<pre>` 预格式化文本

- 保留文本原有的**空格、换行、缩进**。
- `<p>` 会折叠空白，用于普通正文；`<pre>` 保留空白，用于代码、诗歌。

## 五、`<div>` 与 `<span>`

- `<div>`：**块级**，独占一行，可设宽高 → 用于页面分区、布局
- `<span>`：**行内**，不独占一行，宽度由内容决定 → 用于局部文字

```css
div { width: 150px; height: 100px; border: 1px solid red; }
```

★ 重点：根据内容的结构和用途选择标签。
