# Class 1：HTML 基础标签

## 一、HTML 标题标签

HTML 提供了 6 个级别的标题标签，分别为 `<h1>` ~ `<h6>`。

标题级别从 `<h1>` 到 `<h6>` 逐渐降低，主要用于表达网页内容的层级结构。

| 标签 | 含义 | 主要用途 | 常见场景 |
| --- | --- | --- | --- |
| `<h1>` | 一级标题 | 页面最高级标题 | 网站名称、文章大标题 |
| `<h2>` | 二级标题 | 一级标题下的主要章节 | 主要章节标题 |
| `<h3>` | 三级标题 | 二级标题下的子章节 | 小章节标题 |
| `<h4>` | 四级标题 | 进一步细分内容 | 更小的小节 |
| `<h5>` | 五级标题 | 四级标题下的细分 | 较少使用 |
| `<h6>` | 六级标题 | 最低级标题 | 很少使用 |

### 示例

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
...
<h6>六级标题</h6>
```

### 注意

标题标签不仅用于改变文字大小，更重要的作用是表示网页内容的语义和层级关系。

## 二、段落、换行与分隔线

HTML 中常用 `<p>`、`<br>` 和 `<hr>` 对文本内容进行组织。

| 标签 | 含义 | 使用要求 | 常见场景 |
| --- | --- | --- | --- |
| `<p>` | 段落标签 | 成对出现，每个标签表示一个独立段落 | 正文、说明文字 |
| `<br>` | 换行标签 | 单标签，强制换行 | 地址、诗歌等短文本 |
| `<hr>` | 水平分隔线 | 单标签，用于分隔不同主题内容 | 章节、小结分隔 |

### 1. `<p>` 段落标签

基本语法：

```html
<p>这是第一个段落。</p>
<p>这是第二个段落。</p>
```

浏览器通常会在不同段落之间自动产生一定的间距。

### 2. `<br>` 换行标签

`<br>` 用于在同一段内容内部强制换行。

```html
<p>
    第一行文字<br>
    第二行文字
</p>
```

### 注意

- `<p>` 表示一个新的段落。
- `<br>` 只表示换行，并不会产生一个新的段落。

### 3. `<hr>` 分隔标签

`<hr>` 用于表示不同主题或内容之间的分隔。

```html
<p>第一部分内容</p>

<hr>

<p>第二部分内容</p>
```

## 三、HTML 中的空格与换行

在普通 HTML 文本中，浏览器会对连续的空格和换行进行折叠。

例如：

```html
<p>
    春眠不觉晓，
        处处闻啼鸟。
    夜来风雨声，
        花落知多少。
</p>
```

虽然源代码中存在多个空格、缩进和换行，但浏览器通常不会按照源代码中的排版直接显示。

### 1. 连续空格

代码中连续的多个普通空格在浏览器解析时，通常会被折叠为一个空格。

如果需要使用不换行空格，可以使用字符实体：

```html
&nbsp;
```

`&nbsp;` 的含义为 **Non-Breaking Space（不换行空格）**。

### 2. 换行

HTML 源代码中的普通换行在浏览器中不会直接产生网页中的换行效果。

如果需要明确换行，可以使用：

```html
<br>
```

如果需要保留原始排版，可以使用 `<pre>`。

---

## 四、`<pre>` 预格式化文本标签

`<pre>` 表示 **Preformatted Text（预格式化文本）**。

它可以保留文本中的：

- 空格
- 换行
- 缩进

等原始排版格式。

### 基本语法

```html
<pre>
    春眠……
        处处……
</pre>
```

### `<p>` 与 `<pre>` 的区别

| `<p>` | `<pre>` |
| --- | --- |
| 表示普通段落 | 表示预格式化文本 |
| 连续空格会被折叠 | 保留连续空格 |
| 源代码换行通常被折叠 | 保留换行 |
| 适合普通正文 | 适合代码、诗歌、ASCII 图形等 |

### 结论

普通 HTML 元素中的连续空格、换行不会完全按照源代码排版显示。

`<pre>` 标签可以保留文本原有的排版格式。

## 五、基本布局元素：`div` 与 `span`

`div` 和 `span` 是网页布局和内容组织中非常常用的两个通用元素。

### 1. `<div>` 标签

`div` 是 **division（分割、分区）** 的缩写。

它默认是一个块级元素，常用于划分网页结构和不同内容区域。

```html
<div>这是一个块级元素</div>
```

### 主要特点

- 默认独占一行
- 可以包含其他 HTML 元素
- 通常可以设置宽度和高度
- 常用于页面分区和布局

### CSS 示例

```css
div {
    width: 150px;
    height: 100px;
    border: 1px solid red;
}
```

### 2. `<span>` 标签

`span` 表示一个通用的行内容器，一般用于包裹一小段内容。

```html
<p>
    这是一个 <span>行内元素</span>，
    内容不会自动换行。
</p>
```

### 主要特点

- 默认不独占一行
- 通常只占据内容本身需要的空间
- 常用于对文字或其他行内内容进行局部控制
- 经常配合 `class` 或 `id` 使用

---

## 六、`div` 与 `span` 的区别

| 对比项 | `<div>` | `<span>` |
| --- | --- | --- |
| 默认显示类型 | 块级元素 | 行内元素 |
| 是否独占一行 | 是 | 否 |
| 宽度 | 默认占据可用宽度 | 通常由内容决定 |
| width / height | 可以直接设置 | 默认情况下通常不能直接按块级方式设置 |
| 主要用途 | 页面布局、内容分区 | 局部文字、行内内容 |
| 常见场景 | 卡片、导航、页面区域 | 高亮文字、局部样式 |

---

## 七、本节小结

本节主要学习了 HTML 中常见的文本和布局标签：

1. `<h1>` ~ `<h6>` 用于表示不同层级的标题。
2. `<p>` 用于定义段落。
3. `<br>` 用于在内容内部强制换行。
4. `<hr>` 用于不同主题或内容之间的分隔。
5. 普通 HTML 文本中的连续空格和换行通常会被折叠。
6. `<pre>` 可以保留文本原有的空格、换行和缩进。
7. `<div>` 默认是块级元素，常用于网页结构和布局。
8. `<span>` 默认是行内容器，常用于局部内容。
