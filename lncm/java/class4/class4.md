## 3.4 Java 语句

### 3.4.1 从表达式到语句

表达式会产生一个值，例如 `a + b`、`x > 0`。语句会完成一个动作，例如赋值、调用方法或改变执行流程。许多简单语句以分号 `;` 结束。

| 类别 | 示例 | 作用 |
|---|---|---|
| 局部变量声明语句 | `int age = 20;` | 声明并初始化变量 |
| 赋值表达式语句 | `sum = a + b;` | 更新变量的值 |
| 方法调用语句 | `System.out.println(sum);` | 调用方法完成输出 |
| 自增表达式语句 | `count++;` | 将变量加 1 |
| 复合语句（语句块） | `{ statement1; statement2; }` | 把多条语句视为一个整体 |
| 空语句 | `;` | 什么也不执行 |

`package` 和 `import` 是声明，不是方法体中的普通语句；类、字段和方法也属于程序结构中的声明。

### 3.4.2 语句块与作用域

一对大括号 `{}` 包围的内容称为语句块。语句块中的语句按从上到下的顺序执行；在块内声明的局部变量，通常只在该块内有效。

```java
public class BlockDemo {
    public static void main(String[] args) {
        int outer = 10;
        {
            int inner = 20;
            System.out.println(outer + inner);
        }
        // System.out.println(inner); // 错误：inner 已离开作用域
    }
}
```

即使 `if` 或循环体只有一条语句，也建议写大括号。这样可以明确范围，并减少后续增删代码时产生的错误。

### 3.4.3 空语句陷阱

单独一个分号就是空语句。下面代码中的分号已经结束了 `if`，因此大括号中的输出总会执行。

```java
if (score >= 60); {          // 错误：if 控制的是空语句
    System.out.println("及格");
}
```

正确写法：

```java
if (score >= 60) {
    System.out.println("及格");
}
```

## 3.5 程序的四种控制方式

```text
Java 程序流程
├── 顺序结构：语句按书写顺序依次执行
├── 选择结构：根据条件选择分支（if、switch）
├── 循环结构：条件满足时重复执行（while、do-while、for）
└── 转移语句：改变原有流程（break、continue、return）
```

### 3.5.1 顺序结构

顺序结构是最基本的结构。程序从第一条可执行语句开始，逐条执行到最后一条。可以按“输入—处理—输出”检查代码顺序。

```text
开始
  ↓
读取或定义数据
  ↓
计算与处理
  ↓
输出结果
  ↓
结束
```

### 3.5.2 选择、循环与转移结构预览

| 结构 | 解决的问题 | 典型语句 |
|---|---|---|
| 选择 | 条件不同，执行不同代码 | `if`、`if-else`、`switch` |
| 循环 | 重复执行相同或相似任务 | `while`、`do-while`、`for` |
| 转移 | 提前结束或跳过部分代码 | `break`、`continue`、`return` |

选择结构将在第五课展开，循环与转移语句将在第六课展开。

## 3.6 顺序结构实操：输出个人信息

### 3.6.1 题目分析

题目要求保存姓名和年龄，按给定公式计算出生年份，再依次输出三项结果。

| 步骤 | 数据或操作 | Java 表示 |
|---|---|---|
| 1 | 当前年份 | `final int CURRENT_YEAR = 2026;` |
| 2 | 姓名 | `String name = "张三";` |
| 3 | 年龄 | `int age = 20;` |
| 4 | 计算出生年份 | `CURRENT_YEAR - age` |
| 5 | 输出 | `System.out.println(...)` |

### 3.6.2 完整程序

```java
/**
 * 顺序结构实操：输出个人信息
 */
public class PersonalInfo {
    public static void main(String[] args) {
        final int CURRENT_YEAR = 2026;
        String name = "张三";
        int age = 20;

        int birthYear = CURRENT_YEAR - age;

        System.out.println("我的姓名是：" + name);
        System.out.println("我的年龄是：" + age);
        System.out.println("我的出生年份是：" + birthYear);
    }
}
```

运行结果：

```text
我的姓名是：张三
我的年龄是：20
我的出生年份是：2006
```

### 3.6.3 易错点

- `String` 的首字母必须大写。
- 局部变量应先赋值，再参与计算或输出。
- 字符串和变量用 `+` 拼接；`println` 输出后会换行。
- `CURRENT_YEAR` 不需要改变，使用 `final` 表示常量更清楚。
- 本题按 `2026 - age` 计算；若考虑生日是否已过，还需要选择结构处理。

## 3.7 为什么需要选择结构

顺序结构会无条件执行每一步，但很多问题必须先判断条件。例如求解 `ax² + bx + c = 0` 时：

1. 先判断 `a` 是否为 0；若为 0，就不能使用二次方程求根公式。
2. 再计算判别式 `Δ = b² - 4ac`。
3. 根据 `Δ > 0`、`Δ = 0` 或 `Δ < 0` 选择不同结果。

这类“先判断，再决定执行哪一段代码”的问题，就是第五课选择结构要解决的内容。

## 本课小结

- 表达式负责计算，语句负责执行动作。
- 语句块用 `{}` 组织多条语句，并形成局部作用域。
- 顺序结构按书写顺序执行；复杂程序还需要选择、循环和转移结构。
- 写程序时先明确输入、处理和输出，再检查变量是否已初始化、语句是否有多余分号。
